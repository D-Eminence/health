tilt-card.tsx and shared-layout-bg.tsx are the complete public Be UI components.
Their ease, hover-capability and class-name helpers are kept under lib/.
Reveal.tsx follows the Be UI content-reveal recipe with reduced-motion support.
The application uses restrained tilt (max 3 degrees), no glare, and short reveals.
