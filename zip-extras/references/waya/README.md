# Waya + KORO Design System v1.0

This package contains the reusable design-system specification extracted from the supplied project plus a master AI implementation prompt.

## Start here
1. `MASTER_DESIGN_SYSTEM.md` — complete design-system specification.
2. `MASTER_PROMPT.md` — paste into Lovable, Replit, Cursor, coding agents, or another AI builder.
3. `DO_NOTS.md` — hard constraints that protect the visual language.
4. `AUDIT_REFERENCE.md` — source audit used to build the final system.
5. `LEGACY_DESIGN_SYSTEM_REFERENCE.md` — the project's previous design-system document for traceability.

## Recommended usage
Keep these files in the root or `/docs/design-system/` of every project that uses the system. Tell any AI/code agent to read `MASTER_DESIGN_SYSTEM.md` and `DO_NOTS.md` before making UI changes.

The system is organized as Waya Core + KORO Commerce Extension so shared foundations stay consistent while commerce-specific patterns remain explicit.
